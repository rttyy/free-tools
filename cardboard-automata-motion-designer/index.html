How do I stop my follower from sticking?

About this free tool

The Cardboard Automata & Cam Mechanism Studio is a browser-based tool that lets makers, teachers, and papercraft enthusiasts design and simulate kinetic cardboard toys. It provides live motion graphs, pressure angle jam diagnostics, and dual-axle timing synchronization directly in your browser. You can use the basic simulator online for free or get the full offline pack to export vector files and work without an internet connection.

How to use it

  1. Select your cam profile type (pear, eccentric, drop, or custom shape) and set axle parameters.
  2. Adjust friction coefficients and check the live pressure angle graph to detect potential mechanism jams.
  3. Add secondary linkages using the Dynamic Puppet Motion Transformer or align a second axle with the Tandem Timing Synchronizer.
  4. Print 1:1 scale paper templates or export SVG/DXF cut files for laser and craft cutters.

Frequently asked questions

Do I need to install any software to use the offline version?

No installation is needed. The offline pack is delivered as a single self-contained HTML file that opens and runs in any modern web browser without internet access.

What is the difference between the free web version and the $9 offline product?

The free web version lets you design and test mechanisms online. The $9 paid pack allows fully offline desktop use, unlocks 1:1 SVG and DXF vector exports for cutting machines, and includes motion CSV export options.

How does the jam diagnostic feature work?

The simulator calculates cardboard friction coefficients and follower pressure angles across the 360-degree rotation. If the angle exceeds safe limits where friction would lock the mechanism, it highlights the problem zone so you can adjust the cam curve.

Can I use this for laser cutting and craft machines like Cricut?

Yes. The tool exports precise SVG and DXF vector files scaled 1:1, making it easy to send designs directly to laser cutters, vinyl cutters, or craft plotters.
