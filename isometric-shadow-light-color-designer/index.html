About this free tool

The Isometric Shadow & Light Color Designer is a utility for 2D game artists and pixel illustrators looking to eliminate color guesswork. It calculates accurate, hue-shifted highlights and shadows across standard isometric planes directly in your browser. Use the free online interface to build palettes, or download the portable single-file offline pack for your studio workflow.

How to use it

  1. Select your base surface color using the color picker or hex input.
  2. Adjust the light direction, ambient bounce, and hue-shift intensity sliders.
  3. Inspect the generated top, left, and right isometric planes alongside the 5-step shading ramp.
  4. Copy hex codes individually or export the full palette as a .GPL, JSON, or CSV file.

Questions this tool answers

Given my base sprite color, what exact colors should I use on the top, left, and right faces of an isometric object under a specific sun angle so shadows don't look muddy?

You enter: Base surface color (HEX, or Hue 0–360°, Saturation 0–100%, Lightness/Value 0–100%) · Sun altitude angle (0° horizon to 90° zenith) · Sun azimuth angle (0° to 360° around the isometric compass) · Ambient sky fill tint (HEX / Hue) · Direct sun tint (HEX / Hue).
You get: The 3 exact calculated surface colors (HEX, RGB, CSS HSL) for Top (normal [0, 1, 0]), Left (normal [-1, 0, 0]), and Right (normal [0, 0, 1]) faces, including explicit hue shift (°), saturation delta (%), and luminance delta (%) per face.

How do my object's 3 isometric face colors shift if lighting changes from midday sun to a stylized golden hour sunset or neon night, and will adjacent faces remain distinct?

You enter: Base surface color (e.g. brick red #B23A2B) · Target environment lighting profile (Sun altitude 15°, Sun warm amber #FF8C3B at 90% intensity, Ambient twilight violet #36205D at 40% intensity) · Minimum acceptable face-to-face contrast ratio (e.g., WCAG 1.5:1 for pixel art readability).
You get: The 3 re-rendered face colors, the calculated perceived contrast ratio between Top-to-Left, Top-to-Right, and Left-to-Right faces, and an alert if any adjacent faces fall below distinct silhouette threshold.

Frequently asked questions

What is the difference between the free web page and the paid Gumroad product?

The free web page lets you generate values directly in your browser with standard copy features. The paid $9 Gumroad release is a fully portable, single-file HTML pack that works completely offline with no network connection, and unlocks mass exports including .GPL files for Aseprite/GIMP, structured JSON color tokens, and CSV sheets.

How does the tool calculate hue shifts?

Rather than simply raising or lowering brightness, the algorithm shifts the color hue toward warmer tones (like yellow) for direct sunlight surfaces and toward cooler tones (like blue or violet) for ambient shadows. This prevents the washed-out or muddy appearance common in linear RGB scaling.

Can I import the generated palettes directly into Aseprite or GIMP?

Yes. The offline export feature produces valid .GPL (GIMP Palette) files, which can be loaded natively into Aseprite, GIMP, Krita, and other 2D digital art software.

Do I need to install any software or runtime to use the offline version?

No. The offline edition is a single, self-contained HTML file. It has no external CSS, JavaScript libraries, or backend dependencies, and opens immediately in any standard desktop browser.
