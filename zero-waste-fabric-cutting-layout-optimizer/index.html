About this free tool

The Zero-Waste Fabric Cutting & Layout Optimizer helps sewists, quilters, and garment makers calculate exact yardage and organize cut pieces with minimal waste. It automatically packs pattern measurements across standard bolt widths while respecting fabric grainline and directional nap. Use the free online visualizer to plan your cuts before purchasing expensive fabric.

How to use it

  1. Select your target fabric bolt width (36", 44", 54", or 60") and set your selvedge allowance.
  2. Enter pattern piece dimensions, quantities, and toggle directional nap or grainline requirements.
  3. Click optimize to generate an automated 2D cutting map and calculated linear yardage.
  4. Inspect the layout diagram or export cut lists to guide your work at the cutting table.

Questions this tool answers

How many yards or meters of fabric do I actually need to buy for all my rectangular pattern pieces, and can they all fit across my specific bolt width?

You enter: Fabric bolt usable width (e.g., 44 inches or 110 cm) · Desired seam allowance / cut margin between pieces (e.g., 0.5 inches) · List of rectangular pattern pieces with width, height, quantity, and whether 90-degree rotation is allowed (directional fabric vs plain).
You get: The minimum continuous length of fabric bolt required (in inches/yards and cm/meters), whether any piece is too wide to fit the bolt, and a visual 2D layout showing exactly where each piece sits.

How much fabric am I wasting as unusable scraps with this layout, and is it worth buying a wider bolt (e.g. 54 in or 60 in) instead?

You enter: Total pattern area (sum of all piece width * height * quantity) · Bolt usable width under consideration · Required length calculated by the packing visualizer.
You get: Efficiency percentage (Pattern Area / Total Consumed Fabric Area * 100), total scrap area in square inches/cm, and actionable advice on whether a different bolt width or piece rotation would significantly cut waste.

Frequently asked questions

How does the optimizer handle directional prints and grainline orientation?

You can lock pieces to a specific grainline axis or flag fabrics with directional nap. The algorithm will only rotate pieces 180 degrees (or keep them fixed in one orientation) instead of rotating 90 degrees across the grain, preventing inverted patterns and mismatched fabric sheen.

What is the difference between the free web tool and the $9 Gumroad pack?

The web version is free to use online in any browser. The $9 paid pack is a self-contained, single HTML file you download to run completely offline without an internet connection, plus it enables direct CSV cut list exports, JSON project save/reload files, and print-ready cut layout diagrams.

Can this tool handle non-rectangular garment pattern pieces?

The current packing engine calculates layouts based on the bounding box (maximum width and height) of each pattern piece. While irregular curves are treated as rectangles, it provides a safe, realistic yardage estimate that accounts for pattern boundaries without accidental overlap.

Does the yardage calculator account for fabric pre-wash shrinkage?

The tool calculates exact raw cutting space based on the dimensions you enter. We recommend adding your fabric's expected shrinkage rate (typically 3-5% for cotton or linen) to your initial bolt width and piece dimensions before generating the final layout.
