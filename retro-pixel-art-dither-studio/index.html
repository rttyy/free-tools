About this free tool

Retro Pixel Art Dither Studio lets you turn reference artwork into authentic retro sprites or draw animations frame-by-frame directly in your browser. Built for indie game developers, pixel artists, and microcontroller makers, it applies real vintage dithering and exports clean assets in seconds. Use the tool online for free, or grab the offline single-file edition.

How to use it

  1. Import a reference image or create a blank canvas in your target resolution.
  2. Select a hardware palette such as Game Boy, Commodore 64, PICO-8, or 1-bit monochrome.
  3. Choose a dithering algorithm (Bayer, Floyd-Steinberg, or Atkinson) and adjust contrast.
  4. Draw frame-by-frame animations on the timeline and preview playback.
  5. Export as a PNG sprite sheet, GIF, or RGB565 C-byte array for microcontrollers.

Frequently asked questions

What is the difference between the free web tool and the $9 Gumroad version?

The free web version includes the full feature set directly in your browser. The $9 paid edition provides a self-contained, standalone single HTML file that runs entirely offline with zero dependencies, external scripts, or internet connection required.

Which dithering methods and hardware palettes are included?

The studio includes Ordered (Bayer 2x2, 4x4, 8x8), Floyd-Steinberg, and Atkinson error-diffusion dithering. Preloaded hardware palettes include classic 1-bit monochrome, Game Boy (4 shades), Commodore 64, PICO-8, and CGA.

How does the RGB565 C-byte array export work for microcontrollers?

When you choose RGB565 export, the studio formats each pixel into a 16-bit 5-6-5 color value formatted as a C array (`const uint16_t sprite[]`). You can paste this directly into code for Adafruit GFX, TFT_eSPI, or custom drivers on Arduino, ESP32, and Raspberry Pi Pico.

Do I need to install Node, Python, or any desktop software to run it?

No installation is required. The tool runs on standard web technologies and works out of the box in modern desktop browsers like Chrome, Firefox, Edge, and Safari.
