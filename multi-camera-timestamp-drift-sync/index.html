About this free tool

This utility aligns unsynchronized photo sequences taken on multiple camera bodies. Calculate the precise time delta between cameras, preview the merged timeline, and generate clean ExifTool commands to correct your raw files before culling.

How to use it

Frequently asked questions

How to shift EXIF date/time created by time in days, hours, minutes?

You can shift EXIF dates using ExifTool with the `-AllDates` parameter. For example, to move timestamps forward by 1 day, 2 hours, and 15 minutes, run: `exiftool -AllDates+="1:0:0 2:15:0" /path/to/photos`. Replace `+=` with `-=` to shift backward. This updates `DateTimeOriginal`, `CreateDate`, and `ModifyDate` simultaneously.

How can I better organise and file my photos?

A consistent filing structure relies on clean metadata before ingestion. First, synchronize capture timestamps across all camera bodies so sorting by capture time works across your entire set. Then, rename files on import using a standardized pattern like `YYYYMMDD_Event_CameraID_Sequence.ext`. Store raw files in folders organized by date and project name, keeping culling and editing catalogs separated.

Does this tool upload my photos to a server?

No. The free web tool runs entirely client-side inside your browser; no images or metadata leave your computer. For complete air-gapped security on location, the paid version runs 100% offline as a standalone local utility.

Why not just use Lightroom's 'Edit Capture Time' feature?

Lightroom can shift timestamps, but by default, it only updates its internal catalog database unless you manually write metadata back to files. Furthermore, Lightroom cannot easily calculate or compensate for gradual hardware oscillator drift across a 12-hour shoot, whereas ExifTool updates the source files permanently across all software.
